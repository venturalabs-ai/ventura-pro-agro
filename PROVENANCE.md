# Provenance

This file records authorship, source boundaries and third-party references for `ventura-pro-agro`.

## Ventura-authored material

Application code, project-specific domain models, tests, configuration and documentation in this repository are maintained as Ventura Labs AI project material unless a file states otherwise.

## External data and services

The application references or integrates public/external sources such as IBGE, Open-Meteo, ClimaTempo, MAPA/ZARC and Embrapa. Names and trademarks identify data sources or integrations only and do not imply endorsement or affiliation.

Any imported dataset must record its source URL, retrieval date, applicable terms/license and transformation steps when practical.

## Dependencies

Python dependencies are declared in `backend/pyproject.toml`. The SPDX SBOM produced by CI/release workflows is the machine-readable dependency inventory for the corresponding build/release.

## Claims and reproducibility

Agronomic, climate, coverage, security and quality claims must be tied to reproducible tests, datasets or scan artifacts for the referenced commit/release. This software is decision support, not an official agronomic recommendation source.

## Contribution rule

Before adding copied, translated, adapted or imported third-party material, record upstream/source, URL, version/date when practical, license/terms, transformation/reuse type and affected files.
